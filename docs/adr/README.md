# Architecture Decision Records

ADR ghi lại bối cảnh, quyết định và hệ quả của các lựa chọn kỹ thuật quan trọng.
ADR đã được chấp nhận không bị sửa để che mất lịch sử; khi quyết định thay đổi,
tạo ADR mới và đánh dấu ADR cũ là `Superseded`.
