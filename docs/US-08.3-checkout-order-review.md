# US-08.3 — Xem lại đơn hàng trước khi xác nhận

Nguồn yêu cầu: `TechStore_Backlog_2Roles_Backend_Frontend_1to1.md`, US-08.3.
Nhánh: `TSM-67/checkout-order-review`.

## Task đã triển khai

- `T-08.3.1`: DTO và `POST /api/v1/checkout/review` tổng hợp giỏ hàng hiện tại,
  địa chỉ giao hàng và phương thức thanh toán.
- `T-08.3.2`: yêu cầu quyền CUSTOMER; validate address/payment; kiểm tra địa chỉ
  thuộc đúng tài khoản; từ chối giỏ hàng trống; trả trạng thái sẵn sàng theo tồn kho.
- `T-08.3.3`: màn hình review hiển thị sản phẩm, biến thể, số lượng, đơn giá,
  thành tiền, địa chỉ, phương thức thanh toán, tạm tính, phí ship, giảm giá và tổng.
- `T-08.3.4`: frontend gọi API tổng hợp, có loading/error/retry và nút quay lại
  thay đổi địa chỉ hoặc phương thức thanh toán.
- `T-08.3.5`: test service, API validation/phân quyền và hành vi giao diện.

Nút `Đặt hàng` chỉ bật khi backend trả `readyToPlaceOrder=true`. Việc xử lý khi
bấm nút, tạo Order/OrderItem, trừ tồn kho và làm trống giỏ thuộc US-08.4.

## Test case chính

| Trường hợp | Kết quả mong đợi |
| --- | --- |
| Dữ liệu hợp lệ | Hiển thị đủ sản phẩm, biến thể, địa chỉ, payment và các khoản tiền |
| Đổi địa chỉ/payment | Quay đúng bước để chỉnh sửa và có thể trở lại review |
| Giỏ có lỗi tồn kho | Cảnh báo và vô hiệu hóa nút Đặt hàng |
| API review lỗi | Báo lỗi và cho phép thử lại |
| Địa chỉ không thuộc user | 404 `ADDRESS_NOT_FOUND` |
| Thiếu/sai address hoặc payment | 400 `VALIDATION_ERROR` |
| Thiếu token | 401 `INVALID_ACCESS_TOKEN` |
| Giỏ trống | 404 `CART_NOT_FOUND` |
