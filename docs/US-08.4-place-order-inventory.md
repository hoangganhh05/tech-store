# US-08.4 — Đặt hàng và trừ tồn kho

Nguồn yêu cầu: `TechStore_Backlog_2Roles_Backend_Frontend_1to1.md`, US-08.4.
Nhánh: `TSM-68/place-order-inventory`.

## Phạm vi đã triển khai

- `T-08.4.1`: `POST /api/v1/orders` tạo Order và OrderItem từ giỏ hàng của
  CUSTOMER; lưu snapshot địa chỉ và thông tin sản phẩm/biến thể.
- `T-08.4.2`: dùng khóa pessimistic trên từng dòng inventory, sắp xếp variant ID
  để giảm deadlock; thiếu tồn kho trả lỗi có tên sản phẩm/SKU và exception làm
  rollback toàn transaction.
- `T-08.4.3`: chỉ xóa các CartItem sau khi tạo đơn và trừ tồn kho thành công.
- `T-08.4.4`: frontend gọi API, hiển thị lỗi từ server, khóa nút khi đang gửi và
  chuyển sang trang xác nhận với mã đơn hàng.
- `T-08.4.5`: test thành công, thiếu tồn kho, rollback, validation và auth.

Order bắt đầu ở trạng thái `PENDING`; payment status giữ theo phương thức đã
chọn và không được đánh dấu `PAID` bởi luồng này.

## API

```json
POST /api/v1/orders
Authorization: Bearer <customer-token>
{
  "addressId": 12,
  "paymentMethod": "COD"
}
```

Response trả `id`, `orderNumber`, `status`, `totalAmount` và `placedAt`.
Thiếu/sai dữ liệu trả 400; thiếu token trả 401; địa chỉ không thuộc user trả
404; giỏ trống hoặc tồn kho không đủ trả lỗi nghiệp vụ. Admin không được gọi API.

## Kiểm thử

- Unit service đặt hàng kiểm tra tạo Order, gọi trừ kho, xóa giỏ và không mutate
  khi thiếu hàng hoặc inventory ném lỗi.
- Integration checkout kiểm tra authentication, validation và các API liên quan.
- Frontend kiểm tra gọi API đặt hàng, khóa nút, lỗi server và mã đơn xác nhận.

US-08.5 sẽ bổ sung chi tiết xác nhận và email; US-09 sẽ bổ sung lịch sử/chi tiết
đơn hàng.
